# פודקאסט — ניהול מערכות תובלה ושינוע

שבעה פרקים — פרק לכל יחידה, פרק חזרה, ופרק על פערים בין המקורות — סה״כ ~85
דקות. נבנה מאותו חומר של החוברת ובנק השאלות, כדי שהכל יאמר את אותו דבר.

## מה יש כאן

| | |
|---|---|
| `mp3/` | קבצי השמע. **זה מה שמעתיקים לטלפון.** |
| `index.html` | דף נגן — לחיצה מפעילה פרק בדפדפן. נבנה אוטומטית. |
| `scripts/` | התסריטים, מנוקדים. זה מה שעורכים כשרוצים לשנות תוכן. |
| `build.py` | ממיר תסריט לקובץ שמע. |
| `nikud.py` | מנקד תסריטים חדשים או שורות שנוספו. |
| `nikud-overrides.txt` | ניקוד ידני של מונחי הקורס, גובר על הניקוד האוטומטי. |

## בנייה

```
cd podcast && python nikud.py          # לנקד שורות שנוספו
python build.py                        # רק מה שהשתנה
python build.py 03                     # פרק בודד
python build.py --force                # הכל מחדש
```

דורש `edge-tts` ו-`ffmpeg` ב-PATH. הסינתזה מקוונת — צריך אינטרנט.

כל שורה מסונתזת בנפרד ונשמרת ב-`.cache/` לפי גיבוב של הטקסט והקול, כך ששינוי
משפט אחד בונה מחדש שורה אחת ולא פרק שלם. `index.html` נכתב מחדש רק בבנייה
מלאה (בלי ארגומנט של פרק), אחרת הוא היה נחתך לפרקים שנבנו.

## פורמט התסריט

```
# title: שם הפרק                 <- קובע את שם הקובץ ואת תגית ה-ID3
ש: שׁוּרָה שֶׁל הַמְּרַאיֶינֶת            <- קול נשי (Hila)
א: שׁוּרָה שֶׁל הַמַּסְבִּיר              <- קול גברי (Avri)
~4                               <- שקט של 4 שניות (זמן לחשוב על שאלה)
                                 <- שורה ריקה = הפסקה של 0.9 שניות
# הערה                           <- לא נקרא
```

שורת הכותרת נשארת בלי ניקוד: היא הופכת לשם הקובץ ולתגית ה-ID3, ושם קובץ
מנוקד נשבר בהעתקה לטלפון.

## ניקוד

**התסריטים מנוקדים, וזה משנה את הצליל.** הקול העברי של edge-tts מגיב
לניקוד — אותן אותיות בניקוד שונה מייצרות שמע שונה. בלי ניקוד המנוע מנחש,
ומפספס בדיוק במקומות שכואבים: „בעלות אפס״ נקרא „בַּעֲלוּת״ במקום „בְּעָלוּת״,
ו„מסוכן נוסע״ נקרא „מְסֻכָּן״ במקום „מִסּוֹכֵן״.

מוסיפים ניקוד עם `python nikud.py`. הוא מנקד רק מילים שעדיין לא מנוקדות,
ולכן אפשר לתקן ניקוד ביד בתסריט ולהריץ שוב בלי לאבד את התיקון.

שני דברים שכדאי לדעת לפני שנוגעים:

**קמץ קטן נשבר.** המנוע קורא קמץ קטן כ-/a/. „קָדְקוֹדִים״ נשמע בדיוק כמו
„קַדְקוֹדִים״ — נמדד, הפרש 5 מול 1000 בין הגייות שונות באמת. לכן כל קמץ קטן
נכתב מחדש בווי״ו וחולם ב-`nikud-overrides.txt`. חולם חסר וחטף קמץ דווקא
נקראים נכון ואותם משאירים.

**Nakdan לא מכיר את הקורס.** הניקוד האוטומטי מגיע מדיקטה, שטובה בעברית
כללית ונופלת על המונחים כאן — „שיטעון״ יוצא „שֶׁיִּטְעֹן״. כל מונח שנבדק
יושב ב-`nikud-overrides.txt` וגובר עליה. אם מוסיפים מונח חדש לתסריט, שווה
לבדוק שם איך הוא יצא.

**גרש נשאר גרש אסקי.** `ג'י` ולא `ג׳י`. תו הגרש העברי (U+05F3) נשמע אחרת
לגמרי במנוע — נבדק. אין בזה בעיית כיווניות, כי גרש בין שתי אותיות עבריות
ממילא מקבל את כיוון הסביבה.

## החלטות שכדאי לדעת עליהן לפני שמשנים

**דף הנגן מצהיר על כיוון בתגית ולא ב-CSS** — `<html lang="he" dir="rtl">`.
זה מה שקובע את כיוון הבסיס לאלגוריתם הדו-כיווני, והוא שורד גם אם ה-CSS לא
נטען. רצפים משמאל לימין בתוך טקסט עברי — מספר הפרק, אורכו, והמילה `mp3` —
עטופים ב-`<bdi>`, כדי שלא ייגררו למקום אחר לפי מה שמקיף אותם.

**מספרים נכתבים במילים מלאות, לא בספרות** — `אלפיים מאה ושתים עשרה`, לא
`2,112`. המנוע יודע להרחיב ספרות, אבל ביחידה הזאת יש הרבה מספרים שנשמעים
דומה (`276` מול `2,760`), ומילים מלאות מסירות את הספק. אותו כלל לגבי מקפים:
אין מקפים בתסריט. `אינטר מודליות`, לא `אינטר־מודליות` — המקף מבלבל את
ההגייה ומפצל מילים.

**ראשי תיבות בתעתיק עברי** — `ג'י פי אס`, `איי וי אל`, `אן פי קשה`. הקול
מבטא גם אותיות לטיניות, אבל התעתיק נותן את ההגייה שאומרים בכיתה.

**שני קולות ולא אחד.** מונולוג של רבע שעה מאבד את המאזין; חילופי דובר
מחזיקים קשב, ומבנה של שאלה-תשובה מתרגל שליפה ולא רק זיהוי.

**„שאלות לדרך״ בסוף כל פרק** — חמש שאלות, כל אחת עם `~4` לפני התשובה. זה
החלק היחיד שאי אפשר לקבל מהחוברת בזמן נהיגה, ולכן הוא הסיבה שהפודקאסט לא
מיותר.

**פרק 6 בנוי אחרת** — חזרה מרוכזת: שמונה שאלות המרצה עם השהייה לפני כל
תשובה, ואז טבלת המלכודות בקצב מהיר. מיועד להאזנה חוזרת ביום המבחן.

**פרק 7 עוסק בפערים בין המקורות** — בעיקר בכך שסיכום ההרצאות והמצגת מסבירים
אחרת למה נדרשים ארבעה לוויינים ב-GPS (הסיכום: שלושה למיקום ורביעי לגובה;
המצגת: ארבעה נעלמים כולל הזמן). שתי הגרסאות מגיעות לאותו מספר, ושתיהן עלולות
להופיע כניסוח במבחן. הפרק כולל גם את ארבע השאלות השגויות שאותרו במאגר החיצוני
(יר״מ לאוטובוס, קיבולת דרך מקומית, הגדרת Dj, והשוואת רמת מינוע עם שתי תשובות
נכונות).

**מה שירד מהמיקוד נאמר במפורש** — אלגוריתם הסייווינגס של קלארק וורייט מוזכר
בפרק 5 רק כדי שלא תיבהלו מהשם, עם אמירה מפורשת שהוא מחוץ לגזרה.
